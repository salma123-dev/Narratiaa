# Narratiaa

Narratiaa est une application web full-stack pour les lecteurs : bibliothèque personnelle, progression, sessions de lecture, journal, citations, objectifs et statistiques.

## Fonctionnalités

- création de compte avec vérification e-mail, connexion et déconnexion ;
- onboarding avec genres favoris et objectifs ;
- ajout, modification, suppression, recherche et filtrage des livres ;
- import des informations depuis Open Library et détection des doublons ;
- suivi des pages, du temps et de l’historique des sessions ;
- notes, citations, pages et étiquettes ;
- objectifs quotidiens et annuels, séries et statistiques.
